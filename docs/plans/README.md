# docs/plans

One file per in-flight (or completed) ROADMAP item, produced by the
`breakdown` skill (`.claude/skills/breakdown/SKILL.md`) **before**
implementation starts: goal, non-goals, design decisions, week-sized
milestones with executable verify steps, and open questions.

Plans are living documents — update the plan in the same commit when
reality diverges. Keep completed plans; they are the project's design
history.
